# Workspace (Shared with Debian VM)

This directory is automatically mounted inside the Debian VM at `/home/debian/workspace`.

## Usage with Zed:
1. Open this `workspace` folder in Zed on Windows (`File` -> `Open Folder...`).
2. Edit, create, and save code or files here.
3. In your Debian VM terminal (`start.bat`), your files are instantly available at `/home/debian/workspace`.
4. Compile, run, and test your programs directly inside Debian without needing SSH or local network ports!
